## Descripción del proyecto

Este repositorio contiene el Trabajo Práctico Especial de la materia Fundamentos de la Ciencia de Datos - Cursada 2025, 
cuyo objetivo es realizar un análisis completo del dataset dado **"Arbolado Público Lineal 2017-2018"**, datos oficiales recopilados para el Censo de Arbolado Urbano 2017-18

Incluye:
- Análisis exploratorio.
- Limpieza y preparación del dataset.
- Planteo y validación de hipótesis (univariadas, bivariadas y multivariadas).
- Desarrollo de visualizaciones y conclusiones finales.

## Requisitos
![Python](https://img.shields.io/badge/Python-3.13-blue?style=flat&logo=python)
- Jupyter Notebook o JupyterLab
## Instrucciones de ejecución
**Paso 1:** Clonar el repositorio
   ```python
  git clone https://github.com/valentinabulat/TPFundamentos.git
   ```
   ```python
  cd TPFundamentos
   ```

**Paso 2:** Crear un entorno virtual
  - En Windows (PowerShell):
   ```python
  python -m venv venv
  ```
  - En Linux / macOS:
  ```python
  python3 -m venv venv
  ```

**Paso 3:** Activar el entorno
  - En Windows (PowerShell):
   ```python
  .\venv\Scripts\activate
  ```
  - En Linux / macOS:
  ```python
  source venv/bin/activate
   ```
**Paso 4:** Instalar dependencias
  ```python
  pip install -r requirements.txt
   ```
**Paso 5:** Abrí el archivo `.ipynb` y ejecutarlo :)
